# 🧬 Flashcards – Exame de Acesso

Aplicação web de estudo com cartões de memória (flashcards), simulados de exame e suporte offline.

## Como usar
1. Abre o `index.html` no teu browser ou usa a versão instalada no telemóvel.
2. Escolhe a matéria e começa a estudar.
3. Podes adicionar as tuas próprias perguntas na secção de matérias.

## Funcionalidades
- Flashcards interativos com modo de escolha múltipla.
- Simulado de exame cronometrado com cálculo de nota (0 a 20).
- Suporte offline completo (PWA).
- Sistema de backup para exportar e importar os teus cartões (`.json`).
